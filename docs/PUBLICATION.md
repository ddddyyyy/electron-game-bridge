# 公开发布记录

## 本轮清理范围

- 审计了旧仓库的 8 个提交及提交者元数据。发现个人目录、私有样本记录、存档、浏览器缓存、日志和游戏截图被纳入版本控制。
- 移除私有适配、默认游戏、固定安装目录、引擎补丁、专属入口和真实故事/游戏回归脚本。
- 移除包含私人目录、游戏收藏及机器验收路径的历史规格、报告和设计图片，改为通用 Feature 与开发说明。
- 本地运行时、缓存、日志、配置及存档保留在机器上并被忽略，不随源仓库发布。历史中已经提交的数据不能仅靠 .gitignore 清除。
- 经用户授权，完整旧 Git 在仓库外私有备份；发布历史重建为匿名作者的单一初始提交，不保留引用旧提交的分支、标签、reflog 或对象。
- 常见 GitHub/AWS 凭据格式及私钥模式扫描未发现候选；这不保证识别所有自定义秘密。

## 验证

公开版本仅使用自有合成应用，验证空库启动、运行时登记、自动匹配、独立配置、原生应用初始化、忙状态、无图显示及配置恢复。
核心断言继续覆盖路径/参数边界、PE 元数据、运行时身份、数据绑定、写入故障及恢复原件保留。
`node scripts/audit-publication.js` 扫描全部可达提交的文件和匿名邮箱要求，不读取或打印被忽略的玩家资料。

源仓库不包含 Electron 二进制或真实游戏，不承诺任意游戏、所有运行时或跨平台存档兼容。
本轮只完成本地公开源准备，不创建远端仓库、不上传私有备份，也不自动赋予开源许可证。
