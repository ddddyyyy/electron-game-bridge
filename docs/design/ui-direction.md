# 游戏库 UI

使用暖白背景、白色卡片与柔和森林绿强调色。左侧导航组织游戏库、运行环境登记及配置恢复；游戏卡片下方显示选中详情、启动按钮和设置入口。

- 主视图不常驻编辑表单；新增和编辑在同窗口独立面板完成，支持键盘与焦点返回。
- 图片完全可选。缺失、损坏、不支持或超限时使用统一占位和名称，不影响有效保存/启动；不下载封面。
- Electron 版本与匹配结果只读显示；本地运行环境独立登记、单独保存。
- 停止游戏后才能编辑；保存才提交，关闭不保存，失败保留当前输入。不实现持久草稿。
- 窄窗口允许卡片换行和详情堆叠。窗口、权限和游戏初始化由原始应用负责。

文档及测试不附带真实游戏封面、截图或预设游戏。

面向用户统一使用“运行环境”，添加面板标题为“游戏运行环境”。说明其为用于运行游戏的 Electron，文件位置选择电脑上的 Electron.app 或其中的可执行文件；版本仍自动识别。内部 runtime 接口和配置字段保持不变。
