# Feature: Generic Electron Launcher

公开范围为独立游戏库、配置、运行时识别/匹配与原生应用调度。不包含默认游戏、固定个人目录、引擎补丁或真实游戏资源。

## 用户场景与验收

1. 首次启动得到空游戏库和空运行时列表；不读取或登记任何预设游戏。
2. 用户独立登记本地运行时后，程序核对其真实版本、架构和指纹；注册记录的身份不可原位改写。
3. 用户新增名称、安装目录、入口、工作目录和参数。图片可选；游戏的精确 Electron 需求由可靠元数据识别，自动匹配已登记运行时，无版本选择器。
4. 选择卡片后，详情与启动目标一致。原始应用主入口和初始化流程保留，不注入引擎兼容代码。
5. 游戏停止后可编辑；保存才提交，关闭不保存，失败保留当前输入及最后有效配置。独立运行时登记不随游戏面板取消而撤销。
6. 配置损坏、旧版本、外部冲突及写入故障保留原件和恢复备份，不清空配置。已有运行数据无可靠绑定或身份不兼容时拒绝切换，不重建数据目录。

## 非目标

不自动发现所有游戏、下载运行时、分发游戏、构建插件市场、导入私有存档或承诺任意游戏兼容。不迁移技术栈。

## 验证

核心断言、故障注入和空库 UI 集成只用仓库自有合成应用；发布审计检查所有可达提交的文件和元数据。不得把私有样本验证记录作为公开依赖。
